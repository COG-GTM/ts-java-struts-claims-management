Same payment request to the legacy app (left) and the payment service (right)

The legacy app has no payment input form (issue.jsp is a confirmation page), so these forms POST/GET the real /claims/payment/*.do endpoints on 8080 and the equivalent /payment/* endpoints on 8084. Sign in once first; the legacy frames share the browser session. Run with make run (legacy, Java 11) and make payment-run (service, Java 21).
